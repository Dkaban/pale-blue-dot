# Pale Blue Dot

**A visual atlas of humanity's progress beyond Earth.**

Pale Blue Dot brings together public spaceflight data, historical trends, and upcoming missions in an interactive dashboard. Explore how space activity has evolved, which countries and organizations are driving it, and what humanity is launching next.

The dashboard highlights a rotatable launch-site globe, current-year launch activity, upcoming missions, historical trends, national contributions, and notable milestones. Figures are accompanied by data-source links and coverage notes so trends can be understood in context.

## Explore

Visit the [live dashboard](https://dkaban.github.io/pale-blue-dot/).

## Data & attribution

- [Our World in Data / UN Office for Outer Space Affairs](https://ourworldindata.org/grapher/yearly-number-of-objects-launched-into-outer-space): historical **objects launched** data (CC BY; annual figures may lag).
- [The Space Devs / Launch Library 2](https://thespacedevs.com/llapi): current-year launches, actual launch-pad coordinates, and upcoming launch schedules (community-maintained; coverage and dates can change).
- [Natural Earth](https://www.naturalearthdata.com/): public-domain geographic outlines, simplified for the interactive globe.
- Mission milestones are editorial summaries with links to official program websites.

The interactive globe plots recorded launch locations for the current year and groups missions by site. Only records with valid coordinates are plotted. Launch Library coverage is not guaranteed to include all global launches.

Launch counts and objects launched are **different metrics** and are not compared as if they were interchangeable. A spacecraft's commissioning country may differ from its launch provider's country. Updates to the cached feeds run automatically when GitHub Actions is enabled.

Not affiliated with Carl Sagan's estate, NASA, ESA, or the data providers. The name is a tribute to the perspective Carl Sagan helped popularize.
